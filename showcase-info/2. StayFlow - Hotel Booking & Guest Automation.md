## 🛠️ TECHNICAL SPECIFICATIONS & SHOWCASE OVERVIEW

### 1. Live Routes & Navigation

### 2. Core Features & Capabilities
1. **Guest Room Discovery & Booking Portal:**
   - Detailed suite inventory (The Obsidian Grand Suite, Alpine Garden Sanctuary, Highline Penthouse Panorama, Whispering Pines Chalet Villa).
   - Real-time date selection (Check-in / Check-out), duration calculation, and price breakdowns (subtotal, resort fees, local taxes).
   - VIP guest flag, special requests textarea, and instant reservation confirmation generation.
2. **Visual IF/THEN Workflow Automation Engine:**
   - Event Triggers: `On Reservation Created`, `72h Before Check-In`, `On Guest Check-In`, `On Guest Check-Out`.
   - Dispatch Actions: Automated Email Delivery, SMS Alert, Housekeeping Dispatch Webhook, Front Desk Notification.
   - Interactive rule toggles (Active/Inactive), rule execution counters, and simulated event dispatch button.
3. **Operational Logs & Audit Trail:**
   - Real-time workflow dispatch log recording timestamp, rule ID, target recipient, and execution status (`Success (Simulated)`).
   - Live room occupancy matrix displaying available vs. occupied units.
4. **Dual Interface Architecture:**
   - Seamless switching between Guest View (editorial luxury booking portal) and Operator View (dense operational automation terminal).

### 3. Tech Stack
- **Framework:** Next.js (App Router), React 19
- **Backend / Database:** PostgreSQL, Supabase SSR client
- **Styling:** Tailwind CSS (Emerald & Slate Theme, Micro-Interactions)
- **Language:** TypeScript
