## 🛠️ TECHNICAL SPECIFICATIONS & SHOWCASE OVERVIEW

### 1. Live Routes & Navigation

- **CTA:** `DEPLOY_NEXUS.AI`

### 2. Core Features & Capabilities
1. **Streaming AI Chat Interface:**
   - Real-time token streaming animation simulating low-latency LLM generation.
   - Interactive quick-reply prompts and suggestion chips (e.g., "Engineering Capabilities", "Pricing & Retainers", "Code Ownership SLA").
   - Tool-call visualization tags displaying when knowledge base lookups occur.
2. **Knowledge Base (RAG) Document Storage:**
   - Multi-category document administration (Products, Pricing, Policies, Technical Specs, FAQs).
   - Chunk count indicators, similarity threshold adjusters (0.70 - 0.95), and status toggles (Indexed/Draft).
   - Pre-seeded with realistic commercial agency pricing models and technical SLAs.
3. **Conversational Lead Capture Pipeline:**
   - In-conversation lead capture form triggers when users express commercial or project inquiry intent.
   - Lead scoring classifier (`High`, `Medium`, `Qualified`).
   - Admin CRM table with lead name, email, company, expressed interest, and timestamp.
4. **Model Provider Abstraction Layer:**
   - Seamless decoupling between front-end UI and underlying AI service endpoints.
   - Hot-swap support between Infinity Provider (`infinity-instruct-v1`), Anthropic Claude 3.5, and OpenAI GPT-4o.

### 3. Tech Stack
- **Framework:** Next.js (App Router), React 19
- **AI Infrastructure:** Infinity Model Provider Abstraction, Vector Retrieval Simulation
- **Styling:** Tailwind CSS (Cyan / Slate Futuristic Console Aesthetic)
- **Language:** TypeScript
