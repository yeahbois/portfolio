## 🛠️ TECHNICAL SPECIFICATIONS & SHOWCASE OVERVIEW

### 1. Live Routes & Navigation

### 2. Core Features & Capabilities
1. **Financial KPI Terminal Overview:**
   - Real-time Gross Revenue, Operating Expenses, Net Cash Flow, and Outstanding Invoices metrics.
   - Dynamic trend indicators (+14.2% MoM, margin efficiency percentages).
   - Instant date-range scoping and transaction count tally.
2. **Advanced Transaction Ledger Grid:**
   - Full transaction CRUD capability with fields: Date, Description, Category, Counterparty Entity, Type (Income/Expense), Amount, Method, and Status (`Completed`, `Pending`, `Flagged`).
   - Real-time category filtering (Software Revenue, Cloud Infrastructure, Custom Engineering, Facilities, Professional Services, Payroll & HR).
   - Fast keyword search across descriptions, entities, and transaction IDs.
3. **Comprehensive Invoicing Engine:**
   - Multi-item line invoice builder with quantity, unit price, tax rate, and discount fields.
   - Live subtotal, tax calculation, and net total summation.
   - Interactive preview drawer formatted for client presentation and print export.
   - Invoice lifecycle statuses (`Paid`, `Unpaid`, `Overdue`).
4. **Data Terminal Aesthetics & Ergonomics:**
   - Monospaced typography, dark slate color palette, and high-contrast borders for zero eye-fatigue during extended operational use.
   - Restrained micro-animations ensuring instant sub-50ms data interactions.

### 3. Tech Stack
- **Framework:** Next.js (App Router), React 19
- **Visualizations:** Recharts / SVG Financial Charts
- **Database / Storage:** PostgreSQL, Supabase SSR
- **Styling:** Tailwind CSS (Terminal Blue & Slate Dark Theme)
- **Language:** TypeScript
