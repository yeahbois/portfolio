## 🛠️ TECHNICAL SPECIFICATIONS & SHOWCASE OVERVIEW

### 1. Live Routes & Navigation

### 2. Core Features & Capabilities
1. **Interactive 3D WebGL Viewport:**
   - Real-time 3D culinary scene powered by Three.js / React Three Fiber.
   - Interactive orbit controls, touch rotation on mobile, and smooth camera refocusing between dishes.
   - Procedural lighting adjustments highlighting ingredient textures and plating artistry.
2. **Dynamic Signature Dish Showcase:**
   - Detailed tasting dishes including Black Winter Truffle Tagliolini, Dry-Aged Miyazaki Wagyu A5 Ribeye, and Glacier Patagonian Toothfish in Yuzu Miso.
   - Interactive ingredient breakdowns with allergens and sourcing notes.
   - Temperature, prep time, and sommelier wine-pairing recommendations per dish.
3. **Table Reservation Modal:**
   - Date picker, guest party selector (1 to 8+ guests), and dining seating options (Main Dining Room, Chef's Counter, Private Wine Cellar).
   - Instant booking confirmation code generator with booking status badge.
4. **Editorial Luxury UI / UX:**
   - Champagne gold and charcoal velvet aesthetic adhering to high-contrast accessibility standards.
   - Micro-animations, responsive layout with fluid typography, and zero layout shift.

### 3. Tech Stack
- **Framework:** Next.js (App Router), React 19
- **Graphics & 3D:** Three.js, React Three Fiber, Lucide Icons
- **Styling:** Vanilla CSS & Tailwind CSS (Dark Mode, Glassmorphism)
- **Language:** TypeScript (Strict Mode)
